# ClinicCare Mini EMR

A small, secure EMR tool where doctors can search ICD-10 diagnosis codes, record consultation notes with selected codes, list past notes, and search notes by patient or diagnosis code.

- **Backend:** FastAPI, SQLAlchemy, SQLite
- **Frontend:** Nuxt 3, Tailwind CSS
- **Auth:** JWT login for doctors

> Work in progress. Setup and usage instructions will be added as the project is built.
